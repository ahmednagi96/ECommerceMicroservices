# ADR-003: مكتبة الرسائل

## الحالة
مقترح · 2026-11-18

## السياق
محتاجين نبعت ونستقبل Integration Events بين الخدمات على RabbitMQ.
MassTransit v9 بقت مدفوعة. كتبنا Event Bus بإيدنا (6.4) وجربنا Wolverine (6.5).

## القرار
نستخدم Wolverine (MIT) في الإنتاج، ونسيب الـ Event Bus اللي كتبناه
في فرع/tag كمرجع تعليمي.

## الأسباب
- Retry ذكي يفرّق بين الخطأ المؤقت والدائم.
- Outbox و Inbox جاهزين (الموديول 7) بدل ما نكتبهم بإيدنا.
- كود أقل = أخطاء أقل.
- فهمنا اللي تحت المكتبة بالفعل (6.3 و 6.4)، فمش "سحر" بالنسبالنا.

## العواقب
- ➕ كود أقل، ومميزات إنتاج جاهزة.
- ➖ اعتماد على مكتبة خارجية، ولو اتغير ترخيصها نرجع للكود بتاعنا أو نبدّل.
- ➖ شوية "سحر" (الـ Handler بيتلاقي بالاسم)، فلازم نعرف القواعد بتاعته.
